# Archivos descargables

El portfolio sirve actualmente `CV_Samuel_Sanchez_Heredia.pdf` desde esta carpeta.

## Sustituir el CV

1. Coloca el nuevo PDF en esta carpeta.
2. Nómbralo `CV_Samuel_Sanchez_Heredia.pdf`.
3. Si usas otro nombre, actualiza el enlace de descarga en `index.html`.

```html
<a href="files/TU_NOMBRE.pdf" download="TU_NOMBRE.pdf" class="btn btn--cv">
```

El PDF será público al desplegar el portfolio. Revisa que no incluya información sensible antes de publicarlo.
